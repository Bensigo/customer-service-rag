# Managing API keys

Generate an API key under Settings, Developer, API keys. Each key is
shown in full only once at creation, so copy it somewhere safe right
away. Keys carry the same permissions as your account and should never
be committed to a public repository.

If a key leaks, revoke it immediately from the same page and create a
replacement; revoking takes effect within a minute and breaks any
integration still using the old key. You can keep up to five active keys
at once, which lets you rotate them without downtime.
